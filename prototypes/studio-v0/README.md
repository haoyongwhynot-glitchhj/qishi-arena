# 5个模拟工作室评分系统

股票池固定为截图里的17只股票。西部材料只作为样板股做校验，不参与选股。

## 运行

```bash
python3 fetch.py   # 拉取东方财富前复权日线（500个交易日）
python3 run.py     # 输出今日Top3、样板校验、回测与参数优化结果
python3 run.py --today   # 只看今日选股
```

- `tags.py`：人工标签，包括主线关联度、国资背景、市盈率。这些是主观判断，可以直接修改。
- `engine.py`：特征计算和5个工作室的评分函数。

## 5个工作室

| 工作室 | 逻辑 | 门槛 | 持有 |
|---|---|---|---|
| A 老龙回头 | 西部材料型：深跌后底部首次放量站上20日线，或突破后回踩不破再启动 | 主线≥0.5，距250日高点跌幅≥40%，距120日低点涨幅≤60% | 5天 |
| B 龙头接力 | 只做当日涨停且近期最强的股票 | 当日涨停，并且已经连板≥2或20日内涨停≥2次 | 2天 |
| C 主线中军 | 均线多头、成交额大、不追涨停 | 收盘>MA20>MA60，MA60上行，成交额≥8亿，股票池20日中位涨幅>0 | 10天 |
| D 分歧低吸 | 首板或二板次日分歧，守住涨停阳线开盘价 | 昨日涨停（1~2板），今日-5%~+5%，收盘≥昨日开盘价 | 3天 |
| E 量价资金 | 对照组，不看题材和基本面 | 量比≥1.8，收红，收盘在当日振幅上部30%，换手≤15% | 3天 |

## 回测方法

- 信号日次日开盘买入，持有N天后收盘卖出，扣除0.2%成本。次日一字涨停买不进的信号跳过。
- 回测时人工标签全部置为中性。原因是今天的题材判断不能用来评价过去，否则会引入未来函数。
- 前60%的交易日用于选参数，后40%用于验证。只有验证期也有效的改动才保留。

## 优化记录

- A：原规则要求“20日内只有一次放量大阳”，结果漏掉了西部材料10-29的首次突破。现在改为“此前10天至少7天在MA20下方”，并新增“回踩后二次启动”触发条件，能识别出11-09的一字板。
- C：新增股票池强弱过滤。验证期交易从73笔降到10笔，超额收益从-1.21%变为+2.35%。
- D：前两版（主线内落后补涨、强势回踩20日线）在验证期超额为负，已淘汰。第三版分歧低吸在训练期和验证期都为正。
- 网格搜索得到的最优参数在验证期普遍变差，或者样本少于10笔，所以全部保留默认参数。
