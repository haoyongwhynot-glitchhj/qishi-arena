# 项目背景：起势资产 A股五工作室模拟擂台（qishi-arena）

你接手的是一个由 Kiro Web 会话搭建的 A 股模拟交易系统。开始任何工作前先读 `docs/HANDOFF.md`；做个股复核时严格按 `docs/REVIEW_PLAYBOOK.md`。

## 一句话
五个工作室（A–E）各有 10 万元虚拟本金，只交易“董事长”（用户）提供的股票池。程序每天收盘后结算、清理股票池、打分、生成次日买卖计划，每周五做参数进化。你的职责是：个股复核、结算核对、按用户指令改代码、做周复盘。

## 部署与数据权威
- 线上看板：https://q.whynot9527.xyz （HTTP 基本认证，账号密码问用户，不要写进任何文件）。
- 服务器目录：`/opt/qishi-arena`。**服务器上的 pools/、studios/、data/、reports/ 是唯一权威数据**；仓库里的同名目录只是 2026-11-09 的快照，不能拿来覆盖服务器。
- 代码通过 GitHub main 分支发布，服务器每天 08:40、15:25（北京时间）自动执行 `deploy/update.sh` 更新 engine/、deploy/ 和文档，不动数据。
- 行情只用腾讯行情（`engine/data.py`）。东方财富接口在境外服务器不可达，已移除，不要再加回来。

## 绝对规则
1. 不手改台账（`studios/*/ledger.json`）、股票池（`pools/*.csv`）、成交记录（`data/real_trades.csv`）。只通过程序或看板接口（/api/pool、/api/review、/api/note）写入。
2. 不编造成交、价格或公告。查不到就写“未查到”。
3. 参数（`studios/*/genome.json`）只能由 `engine/evolve.py` 按 EVOLUTION.md 的规则修改；授权级变量（must_open、mcap_min、new_batch_first）必须用户批准。
4. 一次只改一个变量；改动写进对应 `studios/*/evolution_log.md`。
5. 密钥（看板密码、录入口令 QISHI_TOKEN、GitHub 令牌）只存在服务器 `/etc/qishi.env` 或环境变量里，绝不写进仓库、提示词或日志。
6. 输出给用户用中文，简洁直接；结论附数字和来源。本项目仅供研究，不构成投资建议。
