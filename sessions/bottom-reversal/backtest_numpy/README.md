# A股短线策略日线回测

## 文件
- `fetch_data.py`：用 baostock 下载沪深A股前复权日线和指数，支持断点续传，结果为 `data/daily.pkl`
- `backtest.py`：策略A（底部横盘→长上影→1~3日反包，对应通达信 V3）和策略B（龙头首次分歧→次日转一致）回测

## 环境
```
pip install pandas numpy baostock
```
baostock 1.x 的 `get_data()` 在 pandas 2.x 下会报错，脚本已绕开，不需要降级 pandas。

## 运行
```
python fetch_data.py 2023-01-01 2026-11-06 12   # 开始日期 结束日期 进程数，全市场约1~1.5小时
python backtest.py
```
下载中断后重新运行同一命令即可续传。删除 `data/names.pkl` 和 `data/parts/` 可重新下载。

## 输出（output/）
- `trades_A.csv`、`trades_B.csv`：每个信号的明细（含未成交原因）
- `summary.csv`：所有分组统计

## 交易规则
| | 策略A | 策略B |
|---|---|---|
| 信号 | 收盘满足 V3 硬条件 | 分歧日：前面≥2个一致板，当天换手板/烂板或断板承接 |
| 买入 | 次日开盘价；一字涨停或高开>3%放弃 | 次日竞价高开 主板2~6%/20cm 3~10%；突破买=突破分歧日最高价；排板买=触及涨停价（假设能成交，偏乐观） |
| 止损 | 买入次日起，跌破反包日最低（可改上影日最低） | 跌破分歧日最低；买入次日开盘低于买入价3%直接卖 |
| 卖出 | 持有5个交易日收盘 | 持有3个交易日收盘 |
| 成本 | 往返0.2% | 往返0.2% |

T+1：买入当天不检查止损。一字跌停当天视为卖不出，顺延到下一交易日开盘。

## 已知局限
- 股票列表取结束日在市股票，已退市股票不在样本内（幸存者偏差，结果偏乐观）
- 不含北交所
- 流通市值用 成交额÷换手率 估算（5日中位数）
- 涨停判定用 pctChg 近似；排板买假设全部成交
- 炸板时间、竞价金额、分时均线等需要分钟/竞价数据，日线回测无法验证
